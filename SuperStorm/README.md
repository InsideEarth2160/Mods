# SuperStorm MOD

Gamers, who install the SuperStorm mod, take profit from new team options. These handle the alliances between human and AI-players automatically depending on the presetting. Moreover, the mod presents changes in the resource - and weather-options. After installing, resources last 4 to 16 times longer and the weather can be influenced.
